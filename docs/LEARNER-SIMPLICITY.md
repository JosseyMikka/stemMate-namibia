# Learner simplicity

The primary help row contains Give me a hint, Explain simply and More options. Optional tools, explanation preference, curriculum resources and privacy information remain discoverable in disclosures. Class projects and teacher controls remain secondary.

An empty guided attempt, explanation or application offers “I’m not sure”. It fills an editable draft and focuses the input; it never submits automatically and is absent when the learner has writing. Independent checks do not offer this action. Existing server attempt/hint/independent gates remain authoritative.

Explanation preferences affect newly started questions, not already-created sessions. No preference is persisted across sign-out/refresh, and no learning-style inference is made. Subject settings collapse after applying new choices. Attachment close returns focus to the now-visible triggering button. Reduced-motion preferences disable animation/transitions.

Validation: eight frontend suites, build/typecheck and lint. Browser checks: uncertainty → progressive hint → reasoning → feedback with blank optional reflection → application → independent check with support disabled; attachment focus return.

This change does not establish accessibility conformance, learning gains, offline support or classroom readiness. Representative learner/device, assistive-technology and school pilot testing remains required; see existing release documentation for privacy/data and capacity items.
