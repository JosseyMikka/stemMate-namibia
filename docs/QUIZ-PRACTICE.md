# Quiz me

## Learner flow

More options → Quiz me opens an optional topic field and explicit AI-processing permission. Natural commands such as “Quiz me on photosynthesis”, “Can you please quiz me on linear equations?” and “I would like a quiz about acids” open the same view with a topic draft. Ordinary questions mentioning a quiz do not trigger it. Choose the subject/curriculum before requesting a quiz; the request does not silently change these choices. Reading style comes from the chat's chosen preference.

Three different questions are generated once and held in a temporary server plan. Only the current question is released. The learner must provide an answer and reasoning (being unsure is acceptable) before AI feedback. Feedback asks for reflection; the optional reflection note is local, then Next question advances. Hints are optional and respect the current class hint limit. Supported status is recorded as a boolean per question. The recap shows attempt and hint counts, not correctness scores, mastery or official grades. Questions are written-response practice, not multiple-choice or adaptive proficiency measurement.

The quiz replaces the visible chat temporarily while preserving its browser draft and attachments. Hidden voice tools are stopped, and controls/visual activities are inactive. Back to chat clears the quiz and returns to the previous chat. Quiz access is disabled during independent practice; start requests with an independent learning-session token are rejected. As elsewhere, browser practice is not a tamper-proof supervised examination.

## Privacy and reliability

Unlike ordinary chat attempts that remain local, quiz answers/reasoning go to the AI provider after explicit permission. They are transient request data, never database records, evaluation events or teacher reports. Feedback and reflections stay in component memory. Server plans retain generated questions, reference reasoning, stage/hint state and support booleans only; they expire after one hour, have ownership checks and a 500-session cap. Cleanup runs every minute and on access. Back to chat requests deletion; if offline, local work still clears and a temporary server plan expires normally. Context change/refresh/sign-out clears browser state. Provider retention is separate; no provider zero-retention or training policy is promised.

Class membership, pause and hint policy are rechecked for each action and after feedback generation. Answer feedback uses an in-flight guard so concurrent submissions/advances cannot race. Failed feedback does not advance the question. The existing shared 60 AI calls/hour cap applies: normally one generation plus three feedback calls for a completed quiz. Request bodies are capped at 30 KB; text lengths and plan shape are bounded. Only current questions/hints are returned; references/future questions are withheld. Client answers are not an authority for marks. No new credentials or dependencies are needed.

AI may generate incorrect, inappropriate-difficulty or off-topic questions and feedback. Generated references are not authenticated marking schemes. The model is instructed to independently verify its reference and learner reasoning, avoid inventing flaws in correct work, use age/subject safeguards and keep feedback short. Partial starter-topic coverage is excluded from quiz prompt metadata so it cannot override a valid requested topic. Subject/grade/qualification constraints and a general-support notice remain. Teacher review and broader learner testing are required before assessed use; no learning-gain claim follows from quiz completion.

## Verification

41 backend tests cover existing learning/teacher/privacy behaviour plus quiz permission, ownership, answer/reasoning/next gates, hidden future questions and reference answers, hint policy/support counts, completed recap, malformed plan rejection, expiry, pause/deletion, request-size limits, independent-stage restriction and safe provider failures. Tests assert learner prose is absent from the quiz store. Six frontend suites cover command recognition and currency/math rendering alongside existing checks. Build, type checking and lint pass.

Browser testing completed a real three-question Mathematics quiz: a deliberately incorrect answer received correct arithmetic feedback, a hint marked question 2 as supported, and the recap showed 2 without STEMMate hints / 1 with hints without a grade. Both entry points, fresh consent, reflection, return-to-chat, independent quiz restriction and 320px width were verified. Live Biology testing initially drifted from photosynthesis to the default osmosis topic; prompt scope was corrected and a repeat produced photosynthesis questions. A word-problem currency rendering issue was fixed for spaced N $ values. AI accuracy/syllabus alignment are not established by these examples. Manual handwritten/PDF marking validation remains separate from quizzes.
